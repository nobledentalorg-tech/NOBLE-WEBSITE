# 🦷 Noble Dental Case Manager

A secure, modern PHP-based patient and case management system for dental clinics.

## ⚙️ Installation
1. Copy `.env.example` → `.env` and set DB credentials.
2. Import `database/ndcm_info.sql`.
3. Run on PHP 8.1+ with PDO enabled.

## 🌐 URL
`https://nobledentalnallagandla.in`

## 🧠 Features
- Patient, case, billing, and prescription modules
- Smart drug engine with interaction checks
- QR-verified digital prescriptions
- Role-based user access
- Progressive Web App (PWA) ready
